Règle de passation

  1. La maquette est la référence esthétique ; l’app actuelle est la référence fonctionnelle. Tout bouton ou action de l’app actuelle absent d’une maquette est conservé.
  2. Une donnée d’exemple de la maquette n’est jamais une donnée produit. Valeurs de Meal-Edit / Food-Edit, étapes 2–3 des recettes, historique des mesures (reconstitué depuis les graphiques) : à remplacer par les données réelles.
  3. Logos et avatar : découpés dans des captures, donc à remplacer par les fichiers sources.
  4. Les couleurs de ce projet sont indicatives : variables officielles G-FLUX prioritaires.
